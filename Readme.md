# CONNECT Internal Management System

> **Note:** This is the initial requirement and feature list. The team can suggest, discuss, and add any necessary features, improvements, or missing requirements as the project progresses.

## 1. Project Overview

**CONNECT Internal Management System** is a web application for managing the internal activities, members, events, meetings, projects, and other organizational data of CONNECT.

The system should act as a **central internal platform** where the CONNECT team can manage its day-to-day operations and track the progress of its activities.

## 2. Admin / Core Team

* Admin login and dashboard
* Manage members and interns
* Manage roles and permissions
* Manage events and activities
* Manage meetings and agendas
* Track plans and progress
* Manage attendance
* View overall organization data

## 3. Members & Interns

* Member/intern profiles
* Active/inactive status
* Role/designation
* Joining date
* Team/department
* Attendance
* Activities/tasks assigned
* Participation history

## 4. Events & Activities

* Create and manage events
* Event details, date, venue and organizers
* Assign members/interns
* Track event status
* Track participation and progress
* Maintain event history

## 5. Meetings

* Create meetings
* Meeting date/time and participants
* Meeting agenda
* Meeting notes/minutes
* Decisions made
* Tasks/action items
* Track action-item progress

## 6. Plans & Progress

* Create organizational plans/projects
* Define tasks and goals
* Assign responsible members
* Track progress/status
* Deadlines
* Completed/pending work
* Progress history

## 7. Attendance

* Record member/intern attendance
* Attendance for meetings/events
* View individual attendance
* View team/overall attendance
* Attendance history

## 8. Dashboard

Dashboard should provide an overview of:

* Active members
* Interns
* Upcoming events
* Upcoming meetings
* Pending tasks
* Ongoing projects
* Attendance
* Recent activities
* Overall progress

## Main Flow

**Admin/Core Team:**
`Login → Manage Members → Manage Events/Meetings → Plans & Tasks → Track Progress`

**Member/Intern:**
`Login → View Assigned Work → Events/Meetings → Attendance → Update Progress`
